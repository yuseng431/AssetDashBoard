# Business Rules

- BR-001: `ASSET_USER`는 소유자 식별 마스터이고 Entra 로그인 계정과 별개다.
- BR-002: 매장 자체가 자산 소유자일 수 있고, 본사 직원도 소유자일 수 있다. 매장과 사용자 매핑은 원천 데이터에 근거한다.
- BR-003: `ASSET.ASSET_USER`가 NULL이면 '미할당'으로 표시한다.
- BR-004: `ASSET.ASSET_CATEGORY_CD`가 NULL이면 '미분류'로 표시한다.
- BR-005: 카테고리 트리는 `ASSET_CATEGORY_PARENT_CD`를 사용한다. 순환 및 누락된 부모 감지 시 안전하게 오류/경고 처리한다.
- BR-006: `ASSET_CATEGORY_LEVEL` 값은 원천 기준이며 계층 실제 깊이와 다를 경우 검증 경고를 남긴다.
- BR-007: 원천 테이블 5개는 UI에서 기본 읽기 전용이며 동기화 외 변경하지 않는다.
- BR-008: 매장 운영 상태와 자산 상태 코드값은 원천 코드표 확정 전 임의로 해석하지 않는다.
- BR-009: 수동 갱신은 관리자만 요청할 수 있다. 인증된 요청자와 실행 시각을 기록한다.
- BR-010: 예약 작업과 수동 실행의 동시 실행은 원천 작업까지 포함해 제어해야 한다.
- BR-011: 동기화 실패 시 성공으로 표시하지 않으며 기존 데이터 유지/롤백 방식은 프로시저 계약으로 확정한다.
- BR-012: 자산 개수는 `ASSET` 행 수를 기준으로 한다. 수량 컬럼이 없으므로 실제 설치 대수와 동일하다고 단정하지 않는다.
