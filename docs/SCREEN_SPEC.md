# Screen Spec

## 1. Dashboard
- KPI: 전체 매장, 자산 레코드, 미분류, 미할당, 상태별 분포.
- 필터: 매장, 자산 분류, 자산 상태.
- 최근 동기화 결과: 성공/실패, 시작/종료, 갱신자.
- `최신정보 갱신` 버튼: 관리자만 표시 및 서버에서도 권한 강제. 실행 중 비활성화/진행 표시.
- 카드/차트 클릭 시 해당 필터가 적용된 목록으로 이동.

## 2. Store List / Detail
- 매장코드, 매장명, 상태, 오픈/리뉴얼/폐점일, 주소 검색.
- 상세에서 연결된 `ASSET_USER`와 자산 목록 표시.

## 3. Asset List / Detail
- 자산코드, 아이템, 카테고리, 소유자, 상태, 등록/수정일 조회.
- `ASSET_USER` 또는 `ASSET_CATEGORY_CD` NULL은 각각 미할당/미분류.

## 4. Category Tree
- 부모/자식 계층 표시, 카테고리 선택 시 하위 분류 포함 검색.
- 순환 관계 발견 시 UI 무한 루프 방지.

## 5. Admin Sync
- 수동 실행 버튼, 최근 실행 목록, 성공/실패/진행 상태, 오류 요약.
- 작업 진행률은 프로시저가 실제 진행률을 제공하지 않으면 표시하지 않음.
