# RICP PRD v0.1

## 목표
약 500개 매장의 IT 자산과 매장 현황을 통합 조회하는 웹 포털. 원천 데이터는 외부 배치가 갱신하며, 관리자 수동 동기화 버튼을 제공한다.

## MVP
- Entra ID 로그인, 역할별 인가(조회자/운영자/관리자).
- 매장 목록/검색/상세: STORE 기준.
- 자산 목록/필터/상세: ASSET + ASSET_ITEM + ASSET_CATEGORY + ASSET_USER 조인.
- 카테고리 계층 탐색 및 하위 분류 포함 필터.
- 자산 소유자(매장 공용 계정 또는 본사 직원) 검색.
- KPI: 매장 수, 자산 수, 미분류 자산, 미할당 자산, 상태별 건수. 상태 코드 의미 확인 후 추가 KPI.
- 관리자 최신정보 갱신 버튼: 지정 프로시저 실행 요청, 상태·최종 결과 표시.

## MVP 제외
자산 직접 수정, 매장 직접 수정, 네트워크 구성도, 프로젝트·리뉴얼 이력, 첨부파일 관리, 모델 EOS 분석은 별도 데이터 모델이 확보되기 전까지 제외.

## 성공 기준
조회 화면이 DB 실제 데이터와 일치; 권한 없는 수동 동기화 차단; 중복 실행 통제; 동기화 오류가 조회 서비스에 영향을 최소화; 동기화 기록 추적 가능.

## 미결정
프로시저명·결과 스키마·실행 시간, 상태 코드 매핑, 자산 소유자와 매장 계정 연결 규칙, 배포 환경.
