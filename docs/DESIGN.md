# RICP Design System

- 콘셉트: Modern Enterprise Operations, 데스크톱 우선 Light Mode.
- Primary `#1E3A5F`, Accent `#2563EB`, Background `#F8FAFC`, Surface `#FFFFFF`.
- Text `#0F172A`, Muted `#64748B`, Border `#E2E8F0`.
- Success `#16A34A`, Warning `#F59E0B`, Danger `#DC2626`.
- 폰트: Pretendard 사용 가능 시 적용, 대체 시스템 폰트 제공.
- Sidebar 240px, Header 64px, Content padding 24px.
- 컴포넌트: KPI Card, DataGrid, Category Tree, Search Filter, Status Chip, Sync Status, Confirm Dialog.
- 상태색은 동일 의미로 통일; 데이터가 없을 때 0과 미수집을 구분.
- '최신정보 갱신'은 사용자 확인 후 요청; 진행 중 버튼 잠금, 성공 시 자동 조회 갱신.
- 실제 동기화가 끝나지 않았는데 성공 메시지 표시 금지.
